Redis for Windows - https://github.com/tporadowski/redis
========================================================

This file provides information about Windows-specific changes to Redis.
For release notes related to original Redis project - please see 00-RELEASENOTES.

--------------------------------------------------------

2026-07-24: Redis 7.2.15 upstream security maintenance

The canonical mingw-7.2 line now includes the exact upstream Redis 7.2.15
patch release, including rejection of crafted stream RESTORE payloads that
could make two consumers share one NACK and trigger a use-after-free. Windows
version resources, documentation, and portable packaging now identify 7.2.15;
the fresh archive name is Redis-x64-7.2.15-mingw.zip.

The historical v7.2.14 and v7.2.14-windows.1 tags and their corresponding
archives remain immutable.

--------------------------------------------------------

2026-07-23: Redis 7.2.14 Windows maintenance revision 1

The canonical mingw-7.2 line is based on the upstream Redis 7.2.14 behavior
baseline and carries the Windows IOCP, FDAPI, QFork, service, Event Log,
console, MinGW64 integration, and applicable upstream security fixes. The
immutable v7.2.14 tag identifies the original promotion archive. Revision 1
is identified by v7.2.14-windows.1 and is distributed as
Redis-x64-7.2.14-mingw-r1.zip after the required clean-build,
focused/full-suite, package, fresh-extraction, soak, and exact
service-restart gates pass.

WINDOWS-7.2-CHANGES.md is the authoritative Windows-versus-Linux behavior and
upgrade guide. In particular, review its QFork/pagefile, fixed-VA/ASLR,
single-I/O-thread, TCP-only/no-TLS, multi-part AOF, disk-backed replication,
native PE-module, synchronous Lua-debugging, Event Log, and service-ACL notes.

The MinGW package configuration targets the bundled jemalloc 5.3.0 tree and is
configured to avoid external MinGW runtime DLL dependencies. Review the test
and release evidence before deployment. Visual Studio/MSI, clean-machine,
antivirus, and unrelated external deployment checks are outside this local
MinGW validation scope.

Windows console mode writes to stdout when `logfile` is empty or the literal
`stdout`, and to the named file otherwise; `syslog-enabled yes` additionally
enables Windows Application Event Log output. Windows service mode enables
Application Event Log output automatically while retaining the configured
logfile sink. The packaged service example therefore writes both
`server_log.txt` and the Application Event Log. Use a distinct
`--service-name` for side-by-side installations because named services share
the Event Log source registration.

--------------------------------------------------------

2026-07-17: Redis 6.2.22 release identity for Windows

The completed Windows port now reports Redis 6.2.22 through INFO, executable
version output, module APIs, RDB metadata, Windows resources, and portable
package naming. The MinGW archive is Redis-x64-6.2.22-mingw.zip.

--------------------------------------------------------

2026-07-15: Redis 6.2.22 behavior integration for Windows

This integration line ports the Redis 6.2.22 core to the existing Windows
IOCP, QFork, service, Event Log, console, and MinGW64 layers. It adds the Redis
6.2 command set, ACLs, RESP3, client tracking, expanded replication, Cluster,
Sentinel, CLI, benchmark, and native module APIs described in
WINDOWS-6.2-CHANGES.md.

The standard portable package is x64, has no OpenSSL/TLS support, and requires
no external MinGW runtime DLLs. Read WINDOWS-6.2-CHANGES.md before upgrading or
enabling Redis 6-only commands.

2017-11-22: Redis 4.0.2 for Windows (alpha)
https://github.com/tporadowski/redis/releases/tag/v4.0.2-alpha

Alpha version of Redis 4.0.2 for Windows.

Redis 4.0.2 for Windows is a merge of Windows-specific changes from latest (unsupported) 3.2.100 release
from MSOpenTech and Redis 4.0.2 and this alpha release consists of:

  * all Redis 4.0.2 features except modules,
  * all executables of Redis (redis-server, redis-cli, redis-benchmark, redis-check-aof, redis-check-rdb).

Main difference to official Redis 4.0.2 (except no support for modules at the moment) is old version
of jemalloc-win dependency, which is planned to be updated to the same version in beta release.
